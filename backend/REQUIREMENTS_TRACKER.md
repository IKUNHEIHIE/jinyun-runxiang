# 后端需求对照与验收清单

依据《津韵润乡_后端功能文档.docx》整理。原文说明：业务能力是需求基线，具体 API 路径、字段、组件和协议是实现建议，因此验收以业务行为为准。这里只记录后端范围；每项须通过接口测试或联调后才能标记完成。

## 范围

- 保留学生、教师、运营和系统管理能力。游客专属页面不做；登录、注册及公开内容浏览保留。
- 美育地图（地标展示、定位、围栏）与小卖部/商城（商品、订单、收益、基金）不再新增功能。仓库现有相关接口和前端调用尚未清理，清理时需要一起调整调用方。
- 活动预约、到场记录和徽章属于活动业务；与地图地标绑定的旧打卡实现需改为活动打卡，不能直接算完成。

## 本轮已验证

- 课程创建、上下架仅管理员可操作；匿名与学生被拒绝。
- 章节可单独查询；本人可查询学习进度；重复上报不重复加分、进度不回退；课程与章节不匹配时拒绝写入。
- 离线事件逐条校验时间、类型、课程章节和进度数据；同一批次多次上报进度仅发一次完成奖励；重复事件按本人且内容一致的条件幂等，其他情况报冲突。移动端只移除服务端确认成功的事件。
- 未发布课程不向普通浏览者暴露目录筛选和章节。
- 社区作品在管理员审核前不进入公开列表，共创投稿必须登录；移除了共创作品的示例点赞数；审核动作限制为合法状态流转。
- 教师无法读取或改动其他教师班级的作业、批改、学情和展册；匿名无法取班级展册。
- 登录用户可修改自己的昵称和个人资料，不能借资料接口修改角色。
- 新密码使用随机盐 scrypt；旧 SHA-256 账户仍能登录并在成功登录后升级密码记录。
- 每次受保护请求按数据库中的最新状态和角色鉴权；旧管理员 Token 在降权或账号停用后立即失效。
- AI 任务仅本人或管理员可查看与取消；模型修改仅管理员可用；取消任务不会在启动时或正常完成时被覆盖为成功。
- 设备命令在没有真实通信时保持待处理，不再返回虚构的执行时间或遥测数据；管理页也显示“待接入/暂无数据”。
- 刷新令牌轮换和退出能使旧令牌失效；课程测验和题库更新经过权限/计分测试；评论、举报和活动签到经过隔离测试。
- 教师学情按班级真实进度、测验与作业记录计算；运营看板在空库显示零且不会生成示例活跃数据。
- 开发库 `jinyun_runxiang_dev` 已应用活动签到、会话表和班级邀请码唯一索引；管理看板可查询。正式库仍需按 V9-V11 迁移。
- 管理端修改的 Vue 页面通过组件语法检查；完整构建暂被仓库缺少 `admin-web/build/plugins`、`build/optimize`、`build/utils` 阻断，需补齐原项目构建配置后再验收。
- 使用 `python -m unittest discover -s tests -p 'test_*.py'` 运行本轮新增的隔离测试，不依赖真实业务库。

## 联调依赖

- AI 模型地址、凭证、支持的模态及失败返回格式。
- 对象存储及文件访问策略。
- 教师端/管理端对未完成接口的实际调用字段。
- 设备通信协议、测试设备及 ACK/超时规则。
